# UCLightcommands

Repository for the UCL Photonics Society | Thorlabs UK Hackathon.

## GitHub Pages site (MKDocs)

This repository now contains an MKDocs site in `docs/` for participants to document progress through hackathon tasks.

### Build environment (uv)

```bash
pip install uv
uv sync
```

### Local preview

```bash
uv run mkdocs serve
```

### Build

```bash
uv run mkdocs build --strict
```
