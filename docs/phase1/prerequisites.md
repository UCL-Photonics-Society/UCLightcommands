# Phase 1️⃣ — Prerequisites

Before the hackathon begins, make sure the following are set up on your computer.

---

## ☑️ Git

Git is the version control tool used to track changes and collaborate on this repository.

- [Download Git](https://git-scm.com/downloads) — available for Windows, macOS, and Linux.
- After installing, configure your identity (required for commits):
    ```bash
    git config --global user.name "Your Name"
    git config --global user.email "your.email@example.com"
    ```
- Full first-time setup guide: [git-scm.com/book/en/v2/Getting-Started-First-Time-Git-Setup](https://git-scm.com/book/en/v2/Getting-Started-First-Time-Git-Setup)

!!! note "Windows users"
    Install [Git for Windows](https://gitforwindows.org/), which bundles Git with **Git Bash** — a terminal that lets you run Git commands on Windows. During installation, select **"Git Bash Here"** and set the default branch name to `main` when prompted.

---

## 💻 Visual Studio Code

VS Code is the recommended editor for writing and previewing Markdown files.

- [Download VS Code](https://code.visualstudio.com/download) — available for Windows, macOS, and Linux.
- VS Code has built-in Git support: [code.visualstudio.com/docs/sourcecontrol/overview](https://code.visualstudio.com/docs/sourcecontrol/overview)

!!! note "Windows users"
    Set Git Bash as your default terminal in VS Code so that Git commands work out of the box:

    1. Open the Command Palette (`Ctrl+Shift+P`) and search for **Terminal: Select Default Profile**.
    2. Select **Git Bash**.

    Full guide: [code.visualstudio.com/docs/terminal/basics](https://code.visualstudio.com/docs/terminal/basics)

---

## 🐈‍⬛ GitHub Account

All contributions go through GitHub. You need an account to create branches, open pull requests, and be added as a repository contributor.

- [Create a GitHub account](https://github.com/signup)
- Once you have an account, send your username to the organiser to be granted **Write** access to the repository.

!!! tip
    Use the same email address for your GitHub account and your Git configuration (`user.email`) — this ensures your commits are correctly linked to your profile.
