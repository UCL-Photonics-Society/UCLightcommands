### LightCommands

Light Commands is a published research project describing a vulnerability in MEMS microphones where modulated light can be used to inject inaudible and invisible voice commands into systems such as Google Assistant, Amazon Alexa, Apple Siri, and Facebook Portal; the team’s USENIX Security 2020 paper demonstrates successful long-range command injection through windows and outlines why light-responsive microphone behavior can create real-world risks for voice-controlled devices.
